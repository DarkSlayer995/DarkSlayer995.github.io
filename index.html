MINECRAFT NETWORK SECURITY

Astra · AntiVPN

PRIVATE PROJECT · AVAILABLE ON REQUEST

Astra is a privately developed Minecraft network security solution designed to identify VPN, proxy, and hosting connections before players join a server. It combines advanced connection screening, configurable security policies, account tracking, and multi-account protection to help server administrators maintain a safer multiplayer environment.

Advanced VPN & Proxy Detection

Advanced connection screening designed for reliable VPN, proxy, and hosting detection while minimizing false positives.

Advanced Filtering

Country, ASN & configurable risk controls.

Persistent Storage

SQLite & MySQL/MariaDB support.

Account Protection & Tracking

IP-based account limits, account association tracking, and multi-account protection.

Technical overview
  • Paper & Folia compatibility
  • Minecraft 1.19.4+
  • Java 17+
  • Configurable security policies
  • Optimized connection screening
  • Persistent account tracking
  • Administrative monitoring
  • Whitelist management

Private development project. Available to selected Minecraft server communities upon request.
